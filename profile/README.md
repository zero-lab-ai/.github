# Zero Lab

Zero Lab secures the AI systems organizations depend on: models, applications, agents, and the infrastructure around them.

We combine an attacker’s mindset with practical engineering to find the paths traditional security misses—and build tools that help others do the same.

Some of our work:

- [PatternForge](https://github.com/zero-lab-ai/PatternForge) — Pattern-aware password analysis and candidate generation.
- [RAGdrag](https://github.com/itsbroken-ai/RAGdrag) — Security assessment tooling for RAG pipelines.
- [AI Security Cheat Sheet](https://github.com/itsbroken-ai/cheatsheet) — Practical techniques for testing and securing AI systems.

Learn more at [zero-lab.ai](https://zero-lab.ai/).
